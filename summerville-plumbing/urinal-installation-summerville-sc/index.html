    Sensor Urinal Installation in Summerville, SC

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Expect years between battery changes. Hardwired units need an electrician first.

    Drainage and Venting for Urinals in Summerville, SC

    Flush Valve Urinal Installation in Summerville, SC

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. We set the volume to the bowl. Wrong settings stain bowls.
