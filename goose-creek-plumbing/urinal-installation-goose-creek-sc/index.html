    Flush Valve Urinal Installation in Goose Creek, SC

    Flush valve urinals are the commercial standard. The volume matches the fixture rating. Wrong settings stain bowls.

    Sloan Flush Valve Installation in Goose Creek, SC

    Sloan Royal valves are on most commercial urinals we see. Each Sloan Royal gets the right inside parts for the bowl, a tuned control stop and a rebuild kit on hand. Optima sensor valves fit the same spud. Battery models need no wiring.

    Flushometer Urinal Installation in Goose Creek

    Manual flushometers are still the most common setup. We install Sloan Royal or Zurn AquaFlush valves on a 3/4 inch supply, adjust the control stop for proper flow, and set the vacuum breaker the right distance above the bowl so it protects the drinking water. Handle side follows the layout. ADA units need the handle within reach.

    Sensor Urinal Installation in Goose Creek, SC

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Expect years between battery changes. Hardwired units need an electrician first.

    ADA-Compliant Urinal Installation in Goose Creek

    At least one urinal in a public restroom with more than one usually has to be accessible. ADA units need a rim at or below 17 inches, a 13-1/2 inch projection and 30 by 48 inches of clear floor. The flush handle has to be easy to reach. We mark it all during rough-in.

    Drainage and Venting for Urinals in Goose Creek, SC

    Urinal drains clog with scale, not paper. Low-flow and waterless units leave mineral buildup in the line, so proper slope and a cleanout matter. A proper vent keeps odor out. We tie in within code distance.
