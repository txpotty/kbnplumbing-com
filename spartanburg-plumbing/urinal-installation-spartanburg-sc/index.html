    Waterless Cartridge Urinals in Spartanburg

    Each waterless brand uses its own cartridge. Falcon, Waterless Co, Kohler and Zurn units all trap odor differently, and the cartridge or sealing liquid has to be replaced after a set number of uses, which in a busy restroom can mean every few months. We set up a schedule with you. Spare cartridges should stay on site.

    Commercial Urinal Installation in Spartanburg

    Offices and restaurants want urinals that survive heavy use. Each unit goes on a carrier with new gaskets and stainless bolts, paired with a matched Sloan or Zurn valve. We check partition spacing too. Most codes want 15 inches from centerline to the side.

    Waterless Urinal Upgrades in Spartanburg

    Switching to waterless is mostly a fixture swap. The old flush valve comes off, the supply gets capped behind the wall, and the new waterless bowl goes on the same carrier with its cartridge housing tied into the existing drain. Many jurisdictions want a capped supply kept for later. That allows a future change back.

    Flushometer Urinal Installation in Spartanburg

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handle side follows the layout. ADA units need the handle within reach.

    Urinal Installation Cost Factors in Spartanburg, SC

    Carrier work is the biggest cost swing. A replacement on an existing carrier with good supply and drain lines costs far less than a new install that needs a carrier, a new 2 inch drain and a 3/4 inch supply run through finished walls. Sensor valves add a few hundred. We itemize each piece.

    Sloan Flush Valve Installation in Spartanburg, SC

    Sloan Royal valves are on most commercial urinals we see. We install them with the correct inside parts kit for the bowl's rated volume, set the control stop so the flush is strong without splashing, and keep rebuild kits on the truck for later service. Optima sensor valves fit the same spud. Battery models need no wiring.
